# Association Patterns

This is the shared helper for recurring ways FruitFacts maps source material
into JSON5 reference files. Update it when comparing sources to existing
encodings or creating new encodings.

## Locations

Placeholder topics:

- Single statewide guide with one broad location
- Trial table with multiple research stations
- Source lists that name regions but not exact sites
- Commercial nursery or patent list with arbitrary headquarters location

## Categories

Placeholder topics:

- Category as recommendation class
- Category as disease resistance group
- Category as harvest season group
- Category as source-table section heading

## Plant Names

Placeholder topics:

- One source row with one cultivar
- One source row with multiple cultivar names
- Marketing names, trademarks, and alternate names
- Rootstocks, seedlings, species, and non-cultivar entries

## Harvest Times

Placeholder topics:

- Exact source dates
- Vague dates such as early, mid, and late month
- Relative dates such as `Redhaven + 5`
- Date ranges and multiple crops

## Recommendation And Trial Meaning

Placeholder topics:

- Recommended varieties
- Tested varieties with neutral results
- Poor performers or not recommended varieties
- Lists copied from other sources

## Citation And Provenance Notes

Placeholder topics:

- Publication URL versus downloadable URL
- Reviewed, revised, accessed, and published dates
- Editions and updates
- Citations that point to more primary sources
